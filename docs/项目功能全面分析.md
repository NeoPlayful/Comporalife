# Comporalife（复利人生）项目功能全面分析

> 产品版本：Personal（个人开源版）｜文档类型：功能需求分析｜状态：规划草案
>
> 产品定位：个人财富管理、银行账单分析、投资组合管理、复利与风险模拟。个人版允许多个独立用户注册，但不支持家庭共享和 SaaS 多租户；未来商业 Cloud 版闭源。
>
> 文档范围：完整的 Comporalife Personal 开源个人版功能规格，不按 完整功能/P2、完整产品 或开发阶段拆分。所有功能均为产品规划，不代表已经开发完成。商业 SaaS 功能单独说明，不属于个人版功能。

---


## 一、核心功能模块


### 1. 用户认证与用户管理（Users / Auth）

平台支持多用户独立注册，各用户只管理自己的数据；不是家庭协作。

- 用户注册、登录、退出
- 邮箱唯一性校验及邮箱验证
- 密码修改、找回及重置
- 获取和编辑个人资料
- 账号状态：active / disabled / pending_verification
- 用户默认币种、时区、日期格式偏好
- 管理员禁用用户及审计（管理能力最小化）
- 登录设备与会话管理
- 账号数据导出、删除申请


**关键规则：**

- 密码使用 Argon2id 或 bcrypt 哈希，禁止明文存储
- JWT 放在 HTTP-only Cookie 时需要 CSRF 防护；Cookie 使用 Secure、SameSite
- 业务查询不得直接信任客户端 user_id；从认证上下文取得
- 禁止普通用户访问其他用户账单、投资或文件


### 2. 个人仪表板（Dashboard）

聚合用户财务概况，提供可解释的指标和趋势。

- 总资产、总负债、净资产
- 当月收入、支出、结余、储蓄率
- 账户余额分布及币种
- 最近交易与待分类流水
- 月度收入支出趋势图
- 消费分类占比图
- 投资本金、当前市值、未实现盈亏（有数据时）
- 财务目标进度
- 数据截至时间、缺失账户提示
- 个人/家庭视图切换（仅商业 Cloud 版支持，个人版不包含）


**关键规则：**

- 净资产 = 已纳入资产总额 − 已纳入负债总额
- 报表必须显示数据口径：时间区间、基准币种、汇率时间、账户范围
- 银行账单导入不等于已取得实时余额；不能伪造余额


### 3. 财务账户管理（Accounts）

统一管理现金、银行、信用卡、投资及负债账户。

- 新建、编辑、归档账户
- 账户类型：cash / bank / credit_card / brokerage / loan / other
- 账户名称、机构名称、币种、备注
- 账户初始余额与余额调整记录
- 手工录入账户余额快照
- 账户列表、排序、筛选
- 隐藏已归档账户
- 账户余额与交易流水核对
- 账户间转账识别与配对
- 多币种账户汇总


**关键规则：**

- 信用卡欠款及贷款余额归类为负债，不能当作负资产流水混算
- 账户归属 user_id；删除账户应优先归档并保留历史关联
- 投资账户的资金余额与持仓市值分别核算，避免双计


### 4. 银行账单导入（Statement Import）

用户从银行下载文件并自行上传；第一版不直接连接银行账户。

- CSV 文件导入
- XLSX / XLS 文件导入（优先 XLSX；XLS 视解析兼容性）
- 文件编码检测：UTF-8、GBK 等
- 表头映射：日期、金额、借贷方向、币种、余额、商户、备注
- 日期、金额格式预览及确认
- 银行模板映射规则保存
- 导入预览、错误行提示、可选择跳过
- 导入批次记录、成功失败数量
- 文件大小、行数、扩展名限制
- 交易指纹去重及冲突人工确认
- 支持撤销未被后续操作引用的导入批次；其余使用可审计回滚
- 原始文件保留策略与删除设置
- OFX / QFX
- PDF 文本账单解析（P2，按银行模板支持；不承诺任意 PDF）


**关键规则：**

- 导入应可重试、幂等，避免重复记账
- 指纹使用用户、账户、日期、金额、方向、银行流水号等；相同金额日期可能是不同交易，不能粗暴去重
- 敏感银行原始文件不得进入日志；解析失败不得泄露完整流水
- 不自动把每笔扣款都当消费；需区分转账、还款、投资买卖


### 5. 交易流水与分类（Transactions）

形成统一可核对的个人财务账本。

- 手工新增收入、支出、转账、余额调整
- 编辑分类、商户、备注、标签
- 交易列表按日期、账户、金额、类别筛选
- 批量分类、批量标记
- 自定义一级和二级分类
- 预置住房、食品、交通、教育、医疗、保险、娱乐等分类
- 分类规则：商户关键词、摘要、金额方向
- 待分类交易收件箱
- 信用卡还款识别
- 账户间转账匹配
- 退款与原始支出关联
- 拆分交易（超市混合消费）
- 定期交易标记
- 附件及票据


**关键规则：**

- 内部转账不计家庭/个人经营性收入或消费
- 信用卡消费计入消费；信用卡还款只作为资产负债转移
- 投资买入不属于日常消费，卖出所得不属于工资收入
- 退款按明确规则冲减原分类支出，并保留交易原始记录


### 6. 收支分析与预算（Analytics / Budgets）

帮助用户理解资金去向和可持续投资结余。

- 按月、季、年统计收入和支出
- 分类占比、分类趋势、商户排行
- 固定支出与可变支出分析
- 月度预算设置及超额提示
- 月度结余与储蓄率
- 历史月份对比与同比（数据足够时）
- 自定义日期范围
- 统计口径包含/排除特定账户
- 异常大额支出标记
- 经常性订阅识别
- 预算结转
- 按分类导出 CSV


**关键规则：**

- 储蓄率 = 净结余 / 有效收入；收入为零时显示不可计算
- 账单缺失月份需标注“不完整”，不应解释为零支出
- 报表默认排除内部转账、投资资产转换等非消费项


### 7. 投资账户与投资组合（Investments / Portfolios）

区分真实投资记录与假设模拟结果。

- 创建多个投资组合
- 资产类别：股票、ETF、债券、现金、基金、其他
- 手工录入买入、卖出、分红、利息、费用
- 持仓数量、成本基础、当前估值
- 现金流入流出与内部调拨
- 累计投入本金、已实现/未实现盈亏
- 资产配置比例图
- 自定义目标配置比例
- 记录估值时间与价格来源
- 投资交易导入模板
- 定期再平衡提示
- 时间加权收益率 TWR
- 资金加权收益率 XIRR
- 历史收益曲线
- 行情数据提供商接口


**关键规则：**

- 收益计算明确费用、分红、税款是否纳入
- 行情未接入时估值为手工输入，不能显示成实时行情
- 投资资金划转与持仓买卖应在统一账本中避免重复计入净资产


### 8. 复利与定投模拟（Compound Simulator）

独立纯计算模块，可不依赖真实账户数据。

- 初始投资本金
- 每月、每年追加投资金额
- 投资期限：年 / 月
- 假设年化收益率
- 按月复利计算及期末投入时点说明
- 本金、累计投入、模拟收益分开展示
- 年度资产曲线与明细表
- 保存、复制、删除模拟方案
- 多情景比较：保守、基准、乐观
- 目标金额反推所需定投
- 每年递增定投
- 提款阶段与退休支取
- 通胀调整后购买力
- 税费与管理费参数


**关键规则：**

- 固定收益率仅为数学假设，不是收益承诺
- 统一明确收益率有效期、复利频率、定投时点与舍入规则
- 计算结果与真实投资收益必须明显区分


### 9. 蒙特卡罗风险模拟（Monte Carlo）

通过随机市场路径而非固定收益率单一路径估计结果区间。

- 设置预期收益率、波动率、投资期限
- 设置初始本金、追加投资、提款
- 设置模拟次数与随机种子
- 展示中位数、P10/P90 等终值分位数
- 展示亏损概率、达标概率
- 模拟最大回撤分布
- 年度财富区间扇形图
- 多资产权重及相关性
- 再平衡假设
- 极端情景压力测试
- 导出模拟参数与结果
- 后台任务执行、取消及进度反馈


**关键规则：**

- 模型假设、收益分布、通胀和税费处理必须可见
- 历史均值和正态分布不保证能准确覆盖尾部风险
- 计算密集任务通过 Worker Threads / 队列运行，不阻塞 Fastify 主线程
- 复现结果需记录模型版本、参数与随机种子


### 10. 财富目标与财务自由规划（Financial Goals）

把实际收支与投资预测连接起来。

- 创建储蓄、购房、教育、退休等目标
- 目标金额、目标日期、初始金额
- 按真实月度结余估算可投资金额
- 预计完成时间及资金缺口
- 目标进度展示
- 通胀调整目标金额
- 应急备用金覆盖月数
- 财务自由目标估算
- 安全提取率作为可编辑假设
- 多目标优先级


**关键规则：**

- 历史结余不等于未来可投资现金流，需用户确认预算
- 提取率仅用于情景规划，不承诺长期可持续


### 11. 数据导出、备份与恢复（Data Management）

开源自部署产品必须支持数据可迁移与可恢复。

- 交易流水 CSV 导出
- 账户、分类、预算导出
- 模拟方案 JSON 导出
- 数据库备份与恢复操作说明
- 导入批次与原始文件删除
- 用户数据整体导出
- 应用内备份/恢复向导
- 备份完整性校验与恢复演练建议


**关键规则：**

- 备份包含银行流水和个人资产信息，应加密并限制访问
- 不能把仅导出 CSV 描述为完整数据库备份


### 12. 系统设置（Settings）

配置个人财务偏好及部署级系统参数。

- 默认币种、日期格式、时区
- 用户资料与密码
- 自定义分类、导入映射规则
- 数据保留及导出
- 复利模拟默认参数
- 会话退出与安全设置
- SMTP 邮件设置（部署级，可选）
- 汇率源配置
- AI API 配置（P2，默认关闭）


## 二、管理与系统运维


### 1. 平台管理后台（Admin Console）

个人开源版提供独立的 `/admin` 管理界面，使用统一 `users` 账户体系，通过 `super_admin`、`admin`、`user` 平台角色控制权限；管理员不默认获得用户私人财务数据读取权限。管理后台用于账号和系统运维，而非代替用户操作其资产。

**管理员仪表板（Admin Dashboard）**

- 注册用户总数、正常/禁用用户数、指定时间段新增用户数
- 登录活跃统计（仅聚合数量）、登录失败及异常事件统计
- 账单导入与模拟任务的待处理、运行、失败、完成数量
- 服务健康、数据库连接、Redis 状态、任务队列与系统错误概览
- 统计指标不得包含用户账户余额、交易明细或投资持仓

**用户管理（Users）**

- 用户列表、分页、邮箱/ID 搜索、角色与状态筛选
- 用户详情：ID、邮箱、角色、状态、注册时间、最近登录时间
- 启用/禁用账号、撤销用户所有会话、发送密码重置通知
- 查看用户登录历史、安全事件及账号操作审计
- 账号删除申请的处理与确认；对不可逆操作执行二次确认
- 禁止管理员通过用户管理接口读取银行账单、投资组合、复利方案或其他私人财务内容

**管理员管理（Admins）**

- `super_admin` 管理 `admin` 角色的授予和撤销
- `admin` 不得提升自身权限或管理 `super_admin`
- 禁止停用/降级最后一个有效 `super_admin`
- 所有角色调整必须写入审计日志
- 不引入自定义角色编辑器、租户角色或复杂 RBAC

**安全与会话（Security）**

- 登录历史查询、异常登录事件查看、用户会话批量撤销
- 管理员登录保护、敏感操作重新验证与 CSRF 防护
- 管理员操作日志：操作者、目标用户、操作、时间、结果及必要的脱敏元数据
- 日志不得记录密码、JWT、银行交易内容、原始账单或敏感密钥

**系统设置与运维（Settings / Operations）**

- 注册开关、邮件服务状态、登录安全参数等部署级设置
- 导入任务、蒙特卡罗计算任务状态、失败原因（脱敏）、安全重试
- 系统健康、运行指标、脱敏错误日志、备份状态与维护操作
- 部署级配置与个人用户偏好分离；敏感密钥仅由安全环境配置提供

**关键规则：**

- 个人版允许多个独立用户，但不建立 `tenant_id`、家庭成员关系或订阅体系
- 用户业务 API 必须基于认证主体 `user_id` 校验所有资源归属，不能信任前端传入的归属 ID
- 后台用户查询只返回账号元数据；后台任务日志只返回脱敏的运维元数据
- 应用层访问控制并不等于数据库超级用户无法读取明文；部署文档须说明自托管管理员的数据库权限边界


### 2. 后台任务管理（Jobs）

处理大型账单解析、统计重算和模拟任务。

- 账单导入任务状态
- 任务失败原因及安全重试
- 导入进度与批次日志
- 队列积压及失败任务监控
- 蒙特卡罗异步计算
- 任务取消与超时


**关键规则：**

- 重试必须幂等
- 后台任务携带明确用户身份和授权范围


### 3. 日志与健康检查（Observability）

保证自部署可排错。

- /health 健康检查
- 结构化应用日志
- 登录与敏感操作审计
- 导入错误统计
- 后台任务错误日志
- 数据库与 Redis 可用性监控
- 日志轮转与保留期限


**关键规则：**

- 禁止记录银行完整流水、密码、令牌和原始导入文件


## 三、核心业务规则与数据一致性


### 1. 统一账本模型

区分账户资金流、消费统计、资产转换与投资交易。

- 交易类型：income / expense / transfer / adjustment / investment
- 账户余额由初始余额、已确认分录与调整计算或对账
- 交易及分录保留来源、导入批次和修改审计
- 账户间转账对应两侧资金变动
- 跨币种转账记录原币金额、兑换汇率与手续费
- 证券交易记录证券数量变化与现金变化
- 避免通过删除历史记录破坏余额一致性


**关键规则：**

- 资金变动建议使用交易头 + 分录（transaction_entries）模型
- 数据库写入使用事务，必要时施加唯一约束和行级锁


### 2. 银行流水识别口径

为分析结果定义可追溯规则。

- 原始流水与标准化交易分层存储
- 区分交易日与入账日
- 识别借贷方向与负数金额
- 跨账户重复流水去重
- 转账与信用卡还款排除消费
- 退款冲减原消费
- 分类规则匹配记录规则来源
- 人工修改优先于自动分类
- 未知类型保留为待确认


**关键规则：**

- 不能通过商户名猜测所有资金用途，允许用户更正
- 所有自动识别结果提供可追溯解释


### 3. 投资与估值口径

确保真实收益与预测模型不混淆。

- 交易成本与手续费归属
- 股息、利息与再投资处理
- 持仓成本计算方法固定并记录
- 市价估值时间戳
- 汇率换算时间戳
- 净资产不重复计算投资现金与证券市值
- 缺失行情时显示估值过期或待补录


## 四、安全与隐私


### 1. 账号与 API 安全

防止用户数据越权和凭据泄露。

- JWT 签发与验证
- HTTP-only / Secure / SameSite Cookie
- Cookie 认证场景 CSRF 防护
- 登录限流与暴力破解防护
- 输入校验、统一错误处理
- 所有查询按 user_id 作用域隔离
- 上传文件白名单与大小限制
- 管理员敏感操作审计
- 依赖漏洞扫描


### 2. 财务数据保护

银行账单和投资信息属于高敏感个人数据。

- 数据库与备份访问控制
- TLS 传输
- 敏感原始文件加密存储
- 文件上传隔离目录与安全文件名
- 删除导入原始文件的策略
- 隐私友好的错误日志
- 用户导出和删除流程
- 可配置备份保留期限
- 第三方 AI 调用默认不发送完整流水


### 3. 数据正确性与恢复

防止重复导入、丢失和统计错账。

## 九、完整功能范围与业务闭环

本章按业务能力而非开发优先级描述 Comporalife Personal 的完整功能范围。所有模块共同组成个人财富管理产品，不划分首版、第二阶段或 完整产品。

### 1. 账户与资产管理闭环

- 用户建立银行、现金、信用卡、证券、贷款等账户，并设置初始余额及币种
- 支持手工录入余额调整、资产与负债，保留修改审计
- 根据交易分录计算账面余额，并与银行对账单核对
- 多币种账户按照指定估值日期的汇率换算到基准币种
- 资产、负债、净资产分别统计，展示数据时间点和估值来源

### 2. 银行账单与收支管理闭环

- 上传 CSV、XLSX、OFX/QFX 及可解析的 PDF 文本账单
- 选择目标账户、识别文件编码和表头、映射日期/金额/币种/对手方等字段
- 预览交易、识别重复、异常行及可能的内部转账
- 用户确认后批量入账，保留导入批次、原始来源及错误报告
- 通过分类规则与人工修正完成收支分类
- 对转账、信用卡还款、证券买入等非消费资金流动进行正确标记，避免重复计算支出
- 生成月度、年度及自定义区间的收入、消费、储蓄率和预算执行报表

### 3. 投资与资产配置闭环

- 创建多个投资组合，录入股票、ETF、基金、债券、现金等资产
- 登记买入、卖出、分红、利息、手续费、税费及现金出入金
- 根据交易与价格快照计算持仓数量、成本、市值、已实现和未实现盈亏
- 统计资产类别、币种、标的及账户维度的配置比例
- 支持自定义目标权重、偏离度与再平衡模拟，不自动执行交易
- 对缺失行情、汇率及历史数据明确提示，不将模拟估值冒充实时数据

### 4. 复利与风险模拟闭环

- 设置本金、定期投入、投入频率、年化收益率、投资期限和复利频率
- 支持通胀、费用、税费、分阶段投入、阶段性提款和退休支取假设
- 计算名义资产、实际购买力、累计本金与复利收益
- 保存多个方案并并排对比，支持参数修改与结果导出
- 蒙特卡罗模拟支持预期收益、波动率、资产相关性、模拟次数及随机种子
- 输出财富终值分布、百分位、目标达成概率、亏损概率、回撤和尾部风险
- 明确标注假设、模型局限、数据来源与随机性，禁止以模拟结果保证未来收益

### 5. 财富目标与个人财务报告闭环

- 建立储蓄、教育、购房、退休、财务自由等自定义目标
- 将目标金额、期限、当前资产、计划投入与模拟情景关联
- 展示目标差距、所需投入、预计达成时间和概率区间
- 生成现金流、净资产、投资表现和财富目标的综合报告
- 支持 CSV/Excel 等数据导出、个人数据备份与恢复，并保留数据口径说明

### 6. 完整功能验收原则

- 所有财务数据以用户账号为隔离边界；不同用户无法读取彼此数据
- 金额计算采用 Decimal，禁止用浮点误差累积到账本
- 账单重复导入不会产生重复交易；可追踪、撤销或纠正导入结果
- 账户间转账、信用卡还款、投资买卖与真实消费有明确区别
- 资产余额、净资产、现金流、投资收益与模拟结果各有独立定义
- 模拟参数、随机种子和模型版本可追溯，结果可复现
- 数据导出、备份、恢复、删除及敏感操作均具有必要安全控制

## 十、个人开源版与商业版功能边界

Comporalife Personal 是完整的个人财富管理开源产品，不以开发阶段限制其功能范围。Comporalife Cloud 是独立的闭源商业 SaaS 产品，以下能力不纳入个人版产品定义：

- SaaS 租户、租户级订阅计费、套餐限额和商业运营后台
- 家庭创建、成员邀请、共享账单授权和家庭汇总财务空间
- 官方托管平台的集中运维、计费与服务等级承诺
- 依赖官方商业协议的自动银行连接服务（若未来提供）

个人版支持多个用户分别注册并管理各自数据，但不包含家庭共享或 SaaS 多租户功能。开源个人版的投资分析、账单管理和模拟能力不因商业版存在而被人为拆分。

## 十一、未来 SaaS 扩展边界（仅预留）


| 设计点 | 个人开源版实现 | 商业版未来扩展 |
|---|---|---|
| 身份 | users + user_id | users + tenant_members |
| 财务归属 | 用户私有账户和交易 | 财务空间 + 成员授权 |
| 计算引擎 | 无状态纯计算模块 | 原样复用核心计算模块 |
| 数据库 | 单数据库、多用户逻辑隔离 | 迁移增加 tenants 与作用域 |
| API | 认证上下文 + 用户作用域 | 增加租户上下文与授权策略 |
| 部署 | 用户自部署 | 官方云托管 |
| 许可 | 开源仓库独立维护 | 商业私有仓库独立维护 |

**迁移约束：** 个人版不预先创建 tenants / households 表。未来需为存量用户创建个人财务空间，迁移账户、流水、预算与投资组合的作用域，检查索引、唯一约束、文件权限和报表统计口径。不可简单把 user_id 改名为 tenant_id。
